# 💰 Fin2Edge

**Fin2Edge** is an interactive financial learning platform designed to make financial concepts simple, engaging, and beginner-friendly.

## ✨ Features

* 📚 **Interactive Financial Lessons** – Learn concepts like saving, investing, loans, and SIPs.
* 🎮 **Gamified Learning Quizzes** – Complete activities and earn points while learning.
* 🏦 **Virtual Bank Simulator** – Practice financial decisions in an interactive virtual environment.
* 🤖 **AI Assistant (Saashya)** – Get help and explanations while learning.
* 🎙️ **Voice Interaction** – Interact with the AI assistant using voice.
* 📈 **Investment Learning** – Understand concepts like SIPs and compounding through practical examples.
